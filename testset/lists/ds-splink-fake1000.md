# ds-splink-fake1000

Автор: Claude subagent (mechanical build from the Splink fake_1000 cluster column), 2026-11-20.

Client search built mechanically from Splink's fake_1000 (repository moj-analytical-services/splink_datasets, file data/fake_1000.csv, commit 75876d806d9eff72072d21878150ee50a96d5f41; URL https://github.com/moj-analytical-services/splink_datasets/blob/75876d806d9eff72072d21878150ee50a96d5f41/data/fake_1000.csv; licence MIT). Attribution: Contains the fake_1000 dataset from Splink's splink_datasets repository, Copyright (c) 2023 MoJ Analytical Services, used under the MIT License. 1,000 synthetic records of 251 people; the cluster column is the ground truth. One client per cluster (224 clients; 27 clusters have no record with both names or no well-formed e-mail and get no client). Representative = the most frequent (first name, surname) pair, ties to the fewest missing fields, then the lowest unique_id; so a stored name or e-mail may itself carry a typo. Queries come from the other records of each cluster: relevant = that cluster's client; acceptable = other clients that contain every query word as a substring of a field, or whose own cluster has a record with the same value. Identical text (case aside) is required, swapped name order expected, typos and short forms nice (at least one relevant in the first 5, other results not scored). Negatives recombine names and e-mail parts of different clients and were checked against every client and all 1,000 records. Built by research/datasets/build/ds_splink_fake1000.py (seed 20261120).
